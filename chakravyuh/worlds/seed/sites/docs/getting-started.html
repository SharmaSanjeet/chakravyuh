Getting started

This walkthrough provisions a local Auralis agent, points it at a scratch tenant, and verifies the ingest path end to end. Budget about ten minutes.

Install the agent

The auralis-agent CLI ships as a static binary and as a Python wheel. Pick one and confirm the version before continuing:

pip install auralis-agent
auralis-agent --version   # expect 2.x

Configure and launch

Reference copies of the sample config and the sandbox environment file are published for offline review.

auralis-agent init --env sandbox        # writes auralis.yaml
auralis-agent start --config auralis.yaml   # serves locally on :8080
auralis-agent tail --component ingest-gateway --follow

Reading platform endpoints

Health and status are plain JSON documents — handy for smoke tests after a deploy:

curl -s localhost:8080/api/health.json
curl -s localhost:8080/status/api/summary.json

Authenticated routes sit behind ingest-gateway and expect a scoped, short-lived bearer token issued per environment. Tokens rotate hourly.
